# Restaurant menu

This is restaurant menu and the users can order fast foods and drinks mainly this one.

## Features
 -user login
 -logout
 -sign up
 -feedback
 - add order
 - payment
 - admin login
 - admin login can see last 10 orders

## Tech Stack
 -JavaScript
 -Python
 -RestApi
 -Xammp
 -Apache
 -Php for fronted
 -Sql
 -MongoDb

 ## Installation

1. Clone the repository

git clone https://github.com/bexruz0708/Restaurant_menu.git

2. Install dependencies

npm install

3. Run the project

npm start
